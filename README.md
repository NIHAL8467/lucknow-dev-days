# Notice Copilot

Notice Copilot is a responsive, browser-only prototype for turning college notice text into a summary, deadlines, extracted actions, a checklist, and source-grounded answers. It also keeps a local history of analyzed notices. The site is dependency-free; no build step or package installation is required.

## Run locally

From the repository root, start a static file server:

```sh
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). You can also open `index.html` directly in a modern browser, though browser storage may behave differently for `file://` pages.

## Try the demo

Choose **Try demo notice** to load the illustrative examination notice, inspect its extracted details, ask a suggested question, and complete an item in the action plan. The sample college notice and its fees, dates, eligibility, and instructions are fictional demo content—not confirmed information about any institution.

## Current prototype scope

- Paste notice text or upload a UTF-8 `.txt` file for local, rule-based extraction.
- The upload picker advertises PDF, DOC, DOCX, and images, but extracting their text requires document/OCR libraries or a server that are not part of this no-dependency prototype. Selecting those file types gives a clear prompt to paste the text instead.
- Summaries and answers are deterministic text-matching results, not generated by an AI model. Answers quote matching notice sentences or explicitly say: “I couldn't find this information in the uploaded notice.”
- Notice history, completed tasks, and best-effort app state are stored in browser `localStorage`; they stay in that browser and are not synced.
- The UI is prepared for a future private AI/document-processing backend. Do not place API keys in the client-side code.
